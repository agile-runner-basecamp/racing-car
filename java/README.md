자동차 이름은 5자를 초과할 수 없다.
-> 예외 처리 필요

전진하는 자동차를 출력할 때 이름을 출력한다.
-> 자동차는 이름과 거리를 속성으로 갖는다.

자동차 이름은 쉼표를 기준으로 구분한다.
-> parser가 필요할 수 있겠다.

random 값이 4이상일 경우 전진한다.
-> 어떻게 테스트 할 것인가?

자동차 경주 완료 시 우승자를 알려준다.
-> findWinners()

# 컨트롤러 흐름

자동차 입력 요청 메시지
사용자 입력

시도 횟수 입력 요청 메시지
사용자 입력

실행 결과 출력 메시지
입력받은 횟수만큼 라운드 진행

경기 완료 시 우승자 출력 메시지

# 기능 구현 목록

Car 객체
- [x] 자동차 이름은 5자를 초과할 수 없다.
- [x] 라운드 진행 시 자동차의 숫자가 4이상일 경우 전진한다.
- [x] 자동차 이름을 매개변수로 받아 거리가 0인 자동차 객체를 초기화한다.
- [x] 자동차 이름이 중복될 경우 예외가 발생한다.

Cars 일급 컬렉션
- [x] 자동차 이름 목록을 매개변수로 받아 자동차 목록을 초기화 할 수 있다.
- [x] 경기 종료 시 우승자를 찾을 수 있다.
- [x] 라운드를 진행한다.
- [x] 숫자 생성기를 매개변수로 받아 전진 조건을 확인한다.

IO
- [x] 사용자 입력을 받는다.
- [x] 사용자 입력을 받아 파싱해 자동차 이름 목록으로 변환할 수 있다.
- [x] 자동차 입력 요청 메시지를 출력한다.
- [x] 시도할 횟수 입력 요청 메시지를 출력한다.
- [x] 실행 결과 메시지를 출력한다.
- [x] 라운드 진행 후 각 자동차의 상태를 출력한다.
- [x] 최종 우승자를 출력한다.

- [x] 시도 횟수는 숫자만 입력할 수 있다.
